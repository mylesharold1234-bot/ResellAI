# Identification and comparable quality

- The upload remains one request to the existing vision model. Its structured response can now contain up to three possible identities and observations tagged as visible, user-supplied, or inferred. A candidate never verifies a SKU or edition. No licensed exact-product catalog or reference-sales dataset is configured.
- eBay Browse exposes listing image URLs and a native search-by-image endpoint. API.SH Mercari search exposes photos and thumbnails. Automated external photo comparison is disabled: eBay's agreement restricts outside AI use of Restricted API content, and API.SH does not grant rights to third-party content. Before enabling visual scoring, obtain applicable permissions and confirm processing/retention terms. eBay-native image search would need approved access and permission to send the user's uploaded photo to eBay. External scoring would require separate vision processing and incur additional cost; none was added.
- The bounded eBay query plan includes a supported model hint and can try one plausible same-model variant. Distinct silhouettes are never promoted as alternates for pricing. Mercari still performs one search page per uncached request (one API.SH credit), without an added candidate fan-out. Existing daily snapshots, deduplication and budgets remain.
- Evidence scoring records model, palette, identifier or edition, condition, size and usable active price. The price amount does not influence similarity. Cohorts that independently pass existing safeguards can support an estimate; the engine uses the cohort median and range, not a price picked by the model. The daily snapshot includes normalized identity, scored listings, selected IDs and calculations.
- Offline matching benchmark: 12 hand-labeled cases. Previous filters: 3 true positives and 2 false positives, 60% precision, 100% recall. Added footwear completeness/type screen: 3 true positives and 0 false positives, 100% precision, 100% recall. Cleats and a sole-separated pair accounted for the difference. This small regression set combines listing-derived and constructed titles; it is not an independent live marketplace accuracy benchmark.
- No verified sale dataset was available to measure pricing error. No live provider calls are needed for the benchmark, and live latency and recommendation availability changes were not measured. The browser regression exercises both cards with controlled API results.
